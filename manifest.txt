usage: arduino-manifest [-h] [-d] [-r] [-v] -b fqbn [file1 file2 ... filen]
  reads arduino surce files, usually .ino and .h files, indentify #include
  statements and print a list of used libaries and their versions.
  It is not recursive, the list doesn't include nested dependencies
  It needs the arduino-cli installed and in the PATH, it parses the
  output of the arduino-cli, so changes in arduino-cli can affect this script.
Options
  -b  fqbn  Fully Qualified Board Name, e.g.: arduino:avr:uno
  -h        print this help file
  -d        print debugging information
  -r        print the requirements.txt file, list only user library names
  -v        include version numbers with -r option
Arguments
  file1 file2 .. filen  source input files to parse, usually *.ino and
                        eventually, *.h
